# Brag Plan: The Mainframe — public landing page (slim)

## What is it

The public landing page for The Mainframe (`/welcome`, this branch, live at
the-mainframe-app.vercel.app) — a launch page whose section headings read like
disclaimers: "Four things it does, and nothing else," "What it will not do, and what you
should know," "Read the code before you trust it."

## The angle

**The landing page that tells you the truth.** Most pages oversell; this one's marketing
is disclaimers. The video is a deadpan tour built from the page's own voice — real
1920×1080 captures of the live page (taken from this branch's dev server), with the
headings doing all the selling by refusing to.

## Hook (first 2-3 seconds)

Mono kicker types, lowercase: "most landing pages oversell." Beat. Statement: "This one
has a section called" — hard cut to the real page section: "What it will not do, and what
you should know."

## Key moments (the middle)

- The real honesty section, full-bleed and slowly pushing in — platform table, both CTAs
  ("Open the Actions tab" / "Build it locally instead"), the "How to get a build" note,
  and the will-not-do guarantees grid, all in one frame. Caption, right-aligned in the
  empty zone: "on the marketing page."
- The page's own heading as kinetic type: "Four things it does." / "And nothing else."
- Real page cards: the platforms section ("What you can actually run today") and the hero
  ("A local-first home for every list you are already keeping.").

## Outro / punchline

Mono setup: "the closing section is titled" → stacked on two strong beats: "Read the code"
/ "before you trust it." → logo lockup + "the-mainframe-app.vercel.app" + the page's own
status pill, verbatim: "Early public release · no versioned releases yet."

## Tone

- Preset: **deadpan** (same voice as the page and the first brag film)
- Interpretation: long holds, sparse motion, one thought per beat; the page's real pixels
  are the star; type scenes use the project's exact tokens (Inter / JetBrains Mono,
  #0E0E10 / #F2F2F0 / #B1B3B7 / #4A9EFF accent, #1F2024 hairlines).

## Format: landscape — 1920x1080
## Duration: 20.5 seconds (scene windows 0–3.0 / 2.8–8.2 / 7.8–15.7 / 15.3–20.5)

## Visual identity

- Background `#0E0E10`, text `#F2F2F0`, muted `#B1B3B7`, accent `#4A9EFF`, borders `#1F2024`
- Inter (statements) + JetBrains Mono (data/captions) — local woff2

## Storyboard

Sequential/interaction: yes — typing, then statement entrance.

### Scene 2 — The section — 5.4s (2.8–8.2)

### Scene 3 — The voice — 7.9s (7.8–15.7)
Stacked kinetic quote, natural timing near the beat grid: "Four things it does." at 8.74,

Sequential/interaction: yes — two-stage quote, card cuts.
Audio intent: soft drop per quote line, one soft click per card cut.
Music: low bed. Transition: crossfade → Scene 4.

### Scene 4 — Punchline — 5.2s (15.3–20.5)

Sequential/interaction: yes — beat-locked text, logo entrance.
Audio intent: dry finality; one soft-impact logo hit.
Music: fade to silence by 20.5s.
