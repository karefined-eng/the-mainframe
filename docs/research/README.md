## Executive Principles for Future Agents

Before proposing any major UI redesign, adding a new domain, or altering marketing copy:

1. **Read [origin.md](../origin.md) First:** Ground yourself in the founder's core emotional experience. Never turn the dashboard into a rigid, judgmental schedule.
2. **Respect the 3–5 Chunking Cap:** Never build an uncapped wall of urgent tasks. Working memory collapses above 5 items.
3. **Ban All Shame Mechanics:** No broken streak counters, no flashing red overdue badges, and no guilt-inducing notification copy.
4. **Preserve the 5 Pre-Modeled Domains:** Do not replace the built-in domains (Goals, Build Ideas, Ventures, Courses, Acquisitions) with a blank-slate canvas.
5. **Keep Storage Sovereign & Offline:** All user data lives in local SQLite with WAL. Sync is strictly direct device-to-device (LAN/USB).
